# Vision (short)
Two faces, one project.
- **Public:** Home (landing, adventure invitation) -> Museum (sideways storytelling: about me, certificates, projects, books, references) -> Connect (the office where visitors talk to me).
- **Private "Office":** content manager (add/remove Museum items without code), newcomer guide with sample data, AI Twin (Gemini) with floating avatar, Developer tab (monitor Atlas, Render, Cloudinary and any service added later), storage library, encrypted secrets vault, hardened security.

Feeling: a visitor should think "this is not a normal portfolio". Visual first, text short, light and fast, great on phones and big screens.
No GitHub or social links on public pages. Privacy first: do not publish personal details the owner has not chosen to publish.
